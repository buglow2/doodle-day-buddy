 MomentPlan — 윈도우7 설치파일(exe) 클라우드로 만들기 (완전 초보용)
 방법: GitHub Desktop (마우스로 클릭만 하면 됩니다. 명령어 X)
════════════════════════════════════════════════════════════

준비물: 인터넷 되는 윈도우 PC 1대. (윈7이 아니어도 됩니다. 윈10/11에서 만들어서
        결과 exe를 윈7 사람에게 주는 방식입니다.)


─────────────────────────────────────────────
 STEP 1. GitHub(깃허브) 계정 만들기  — 약 3분
─────────────────────────────────────────────
1) 인터넷 창에서  github.com  접속
2) 오른쪽 위 "Sign up" 클릭
3) 이메일 / 비밀번호 / 아이디(username) 정하고 가입
4) 이메일로 온 인증코드 입력하면 끝
   ※ 무료 계정이면 충분합니다.


─────────────────────────────────────────────
 STEP 2. GitHub Desktop 프로그램 설치  — 약 3분
─────────────────────────────────────────────
1) 인터넷 창에서  desktop.github.com  접속
2) "Download for Windows" 클릭 → 다운로드된 파일 실행 → 자동 설치
3) 설치 후 프로그램이 열리면 "Sign in to GitHub.com" 클릭
4) STEP 1에서 만든 계정으로 로그인 (브라우저가 열리며 "Authorize" 누르면 됨)


─────────────────────────────────────────────
 STEP 3. 프로젝트 폴더를 GitHub에 올리기  — 약 5분
─────────────────────────────────────────────
1) GitHub Desktop 위쪽 메뉴 → File → "Add local repository..." 클릭
2) "Choose..." 눌러서 이 프로젝트 폴더를 선택
      →  E:\doodle-day-buddy   (이 파일이 들어있는 폴더)
3) "이 폴더는 git 저장소가 아닙니다" 같은 안내가 나오면
      → 파란 글씨 "create a repository" 클릭
4) 창이 뜨면 그대로 두고 아래 "Create repository" 클릭
      (Name 은 자동으로 doodle-day-buddy 로 채워져 있음)
5) 잠깐 기다리면 왼쪽에 파일 목록이 뜹니다. (node_modules 같은 큰 폴더는
      .gitignore 덕분에 자동으로 빠집니다 — 신경 안 써도 됨)
6) 왼쪽 아래 "Summary" 칸에 아무거나 입력 (예: first)
      → 파란 버튼 "Commit to main" 클릭
7) 위쪽에 나타나는 "Publish repository" 버튼 클릭
      → 창에서 ★ "Keep this code private" 에 체크 (소스가 남에게 안 보이게)
      → "Publish repository" 클릭
   ※ 이걸로 코드가 GitHub 클라우드에 올라갔습니다.


─────────────────────────────────────────────
 STEP 4. 클라우드가 exe 를 자동으로 만들기  — 약 10~20분 (자동)
─────────────────────────────────────────────
올리는 순간 자동으로 빌드가 시작됩니다. 확인/다운로드는 인터넷 브라우저에서:

1) 브라우저에서  github.com  접속 → 로그인
2) 오른쪽 위 내 프로필 → "Your repositories" → doodle-day-buddy 클릭
3) 위쪽 탭 중 "Actions" 클릭
4) "Build installers" 라는 실행이 노란 점(진행중)으로 보입니다.
      → 초록 체크(✓)로 바뀔 때까지 기다립니다 (10~20분, 커피 한 잔 ☕)
      ※ 혹시 자동으로 시작 안 됐으면: 왼쪽 "Build installers" 클릭 →
        오른쪽 "Run workflow" 버튼 → "Run workflow" 한 번 더 클릭
5) 초록 체크가 되면 그 실행을 클릭
6) 맨 아래로 스크롤 → "Artifacts" 부분에 3개가 보입니다:
      • DoodleDayBuddy-Mac
      • DoodleDayBuddy-Windows      (윈10/11용)
      • DoodleDayBuddy-Windows7     ← ★ 이게 윈도우7용
7) "DoodleDayBuddy-Windows7" 클릭 → zip 파일이 다운로드됨
8) 그 zip 을 풀면 안에  ...ia32.exe  설치파일이 있습니다.
      → 이 exe 를 윈도우7 사용자에게 주면 끝! (32비트라 32·64비트 윈7 모두 실행)


─────────────────────────────────────────────
 앞으로 앱을 고칠 때마다 (재빌드)
─────────────────────────────────────────────
저(클로드)가 앱을 수정해서 dist 를 갱신하면 →
 GitHub Desktop 열기 → Summary 칸에 아무거나 입력 → "Commit to main"
 → 위쪽 "Push origin" 클릭 → 자동으로 다시 빌드됩니다.
 그다음 STEP 4 처럼 Actions 에서 새 exe 를 받으면 됩니다.


─────────────────────────────────────────────
 자주 막히는 부분
─────────────────────────────────────────────
• Actions 탭에 빨간 X(실패) 가 뜨면 → 그 실행을 클릭해서 빨간 부분 캡처해
  저에게 보여주세요. 바로 고쳐드립니다.
• 무료 비공개(private) 저장소도 한 달 2000분까지 무료라 넉넉합니다.
• Mac/윈10 빌드가 실패해도 윈7 빌드만 성공하면 윈7 exe 는 받을 수 있습니다.
