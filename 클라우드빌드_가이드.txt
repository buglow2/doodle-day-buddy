● 이게 뭔가요?
  Mac 앱은 Mac에서만 만들 수 있고, Windows7 앱은 옛날 설정이 필요합니다.
  GitHub(깃허브)라는 무료 서비스가 인터넷 상에서 Mac/Windows 컴퓨터를
  잠깐 빌려주고, 거기서 자동으로 설치본을 만들어 줍니다.
  → 사장님은 파일만 올리면, 결과물(설치파일)을 다운받기만 하면 됩니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 준비: GitHub 계정 만들기 (한 번만)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1) github.com 접속 → Sign up → 이메일/비번으로 가입 (무료)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 1단계: 저장소(repository) 만들기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1) 로그인 후 오른쪽 위 "+" → "New repository"
  2) Repository name: doodle-day-buddy (아무 이름 가능)
  3) ★중요: "Private"(비공개)를 선택하세요.
     (소스가 남에게 안 보이게. 우리 앱은 소스가 노출되면 안 됩니다)
  4) 초록색 "Create repository" 클릭


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 2단계: 파일 올리기 (제일 쉬운 방법 — 드래그)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  올릴 것: 이 폴더(doodle-day-buddy) 안에서 아래만 올리면 됩니다.
     ✔ dist         (폴더)   ← 앱 알맹이
     ✔ docs         (폴더)   ← 약관 문서
     ✔ electron-app (폴더)   ← 단, 그 안의 node_modules / release / dist 는 빼고
     ✔ .github      (폴더)   ← 빌드 명령서 (안 보이면 아래 ※ 참고)
     ✔ .gitignore   (파일)

  올리는 법:
  1) 저장소 화면에서 "uploading an existing file" 링크 클릭
     (또는 Add file → Upload files)
  2) 위 폴더/파일들을 창으로 드래그해서 놓기
  3) 맨 아래 초록색 "Commit changes" 클릭

  ※ .github 폴더가 파일탐색기에서 안 보이면:
     탐색기 상단 "보기" → "숨긴 항목" 체크하면 보입니다.
     이게 없으면 자동 빌드가 안 되니 꼭 함께 올리세요.

  ※ node_modules 폴더는 절대 올리지 마세요 (수만 개 파일, 불필요).
     .gitignore 가 알아서 걸러주지만, 드래그할 때 빼고 올리면 됩니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 3단계: 빌드 실행 & 결과 받기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1) 파일을 올리면 자동으로 빌드가 시작됩니다.
  2) 저장소 상단 "Actions" 탭 클릭 → "Build installers" 진행 상황 확인
     (노란 점=진행중, 초록 체크=완료, 빨간 X=실패)
     - Mac + Windows + Windows7 세 개가 동시에 만들어집니다. 약 5~10분.
  3) 완료되면 그 실행 화면 맨 아래 "Artifacts"에 3개가 생깁니다:
     ▸ DoodleDayBuddy-Mac       → 클릭하면 .dmg 들어있는 zip 다운로드
     ▸ DoodleDayBuddy-Windows   → 최신 윈도우용 설치 exe
     ▸ DoodleDayBuddy-Windows7  → 윈도우7용 설치 exe
  4) 각각 다운받아 압축 풀면 설치파일 완성!


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 다음에 새 버전 낼 때
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1) 저에게 수정 요청 → 새 dist 를 폴더에 반영
  2) GitHub 저장소에서 dist 폴더를 새 파일로 다시 올리기(덮어쓰기)
  3) 자동으로 다시 빌드됨 → Actions 에서 새 결과물 다운로드
  (또는 Actions 탭 → Run workflow 버튼으로 수동 실행도 가능)

● Mac 설치본은 "서명"이 안 되어 있어, 고객이 처음 열 때
  "확인되지 않은 개발자" 경고가 뜹니다.
  → 고객 안내: 앱을 마우스 오른쪽 클릭 → "열기" → "열기" 재확인.
  → 이 경고를 없애려면 Apple 개발자 계정(연 $99)이 필요합니다. (선택)

● Windows 설치본도 처음엔 "Windows가 PC를 보호했습니다" 경고가
  뜰 수 있습니다 → "추가 정보" → "실행"으로 진행.
  → 없애려면 코드서명 인증서(유료)가 필요합니다. (선택)

● Windows7은 지원 종료된 옛 OS라, 되도록 Windows10 이상을 권장하세요.
  Win7용은 "혹시 옛 컴퓨터 고객"을 위한 보조 수단으로만 생각하시면 됩니다.

● GitHub 무료 플랜은 비공개 저장소도 매월 넉넉한 빌드 시간을 줍니다
  (개인 판매 규모에선 무료로 충분).
