 MomentPlan — 기존 사용자에게 "업데이트 알림" 띄우기 (완전 초보용)
 원리: 앱은 켜질 때마다 클라우드(Supabase)의 "버전 게시판"을 봅니다.
       거기 적힌 최신 버전이 자기 버전보다 높으면, 화면 우측 아래에
       "🔔 새 버전 사용 가능" 알림이 저절로 뜹니다.
 => 새 설치파일을 인터넷에 올려두고, 게시판에 "최신버전 + 다운로드주소"
    한 줄만 바꿔주면 모든 사용자에게 알림이 갑니다.
════════════════════════════════════════════════════════════

 오늘 올릴 버전 번호:  0.93.0
 (앱 내부 버전을 이미 0.93.0 으로 올려두었습니다. 그대로 진행하면 됩니다.)


─────────────────────────────────────────────
 STEP 1. 새 설치파일(exe) 만들기  — 약 10~20분 (자동)
─────────────────────────────────────────────
1) GitHub Desktop 프로그램 열기
2) 왼쪽 아래 "Summary" 칸에 아무거나 입력 (예: update 0.93.0)
3) 파란 버튼 "Commit to main" 클릭
4) 위쪽 "Push origin" 클릭
   → 클라우드가 자동으로 0.93.0 설치파일을 만들기 시작합니다.
5) 브라우저에서 github.com → 내 저장소 → 위쪽 "Actions" 탭
   → 초록 체크(✓)가 될 때까지 기다림 (커피 한 잔 ☕)
6) 그 실행을 클릭 → 맨 아래 "Artifacts" 에서 설치파일 zip 다운로드
      • DoodleDayBuddy-Windows      (윈10/11용)
      • DoodleDayBuddy-Windows7     (윈7용, ...ia32.exe)
7) zip 을 풀어서 안의 exe 파일을 꺼내 둡니다.


─────────────────────────────────────────────
 STEP 2. 설치파일을 "다운로드 링크" 나오는 곳에 올리기
─────────────────────────────────────────────
사용자가 로그인 없이 바로 받을 수 있는 공개 주소가 필요합니다.
아래 둘 중 편한 방법 하나만 하면 됩니다.

■ 방법 A — GitHub Releases  (추천, 무료, 링크가 안 바뀜)
  1) 브라우저에서 내 저장소 페이지 → 오른쪽 "Releases" 클릭
  2) "Draft a new release" (또는 "Create a new release") 클릭
  3) "Choose a tag" 칸에  v0.93.0  입력 → "Create new tag" 선택
  4) 아래 큰 네모 칸에 STEP 1의 exe 파일을 마우스로 끌어다 놓기
  5) 초록 버튼 "Publish release" 클릭
  6) 올라온 exe 파일에 우클릭 → "링크 주소 복사"
     → 이 주소가 다운로드 링크입니다. (메모장에 붙여넣어 두기)

■ 방법 B — 구글 드라이브 / 드롭박스  (가장 쉬움)
  1) 드라이브에 exe 업로드
  2) 파일 우클릭 → 공유 → "링크가 있는 모든 사용자" 로 변경
  3) "링크 복사" → 이 주소가 다운로드 링크입니다.


─────────────────────────────────────────────
 STEP 3. 클라우드 게시판에 "최신 버전" 올리기  — 30초
─────────────────────────────────────────────
1) Supabase 대시보드 접속 → 왼쪽 메뉴 "SQL Editor" 클릭
2) 아래 내용을 붙여넣고, 따옴표 안의 링크만 STEP 2 주소로 바꾼 뒤 Run:

   update app_meta set
     latest_version = '0.93.0',
     download_url   = '여기에_STEP2에서_복사한_다운로드_링크',
     notes          = '팀 공지 기능, 일정 이미지·엑셀 공유, 새 테마 2종 추가'
   where id = 1;

3) 끝! 이 순간부터 사용자가 앱을 켜면 우측 아래에
   "🔔 새 버전 0.93.0 사용 가능" 알림이 뜹니다.
   notes 칸에 적은 글이 알림 안에 그대로 보입니다.


─────────────────────────────────────────────
 알아두면 좋은 점
─────────────────────────────────────────────
• 이 방식은 "알림 + 사용자가 직접 새 exe 받아 재설치" 입니다.
  (클릭 한 번에 자동 교체되는 방식은 코드서명 인증서 + 서버가 필요해
   지금 단계에서는 이 방식이 가장 현실적입니다.)
• 사용자는 알림에서 "나중에"(잠시 닫기) 또는
  "건너뛰기"(그 버전 알림 다시 안 봄) 를 고를 수 있습니다.
• 다음에 또 업데이트할 때는 버전 번호만 0.93.0 → 0.94.0 처럼 올리고
  STEP 1~3 을 똑같이 반복하면 됩니다.
  (앱 내부 버전 올리는 건 제가 코드에서 해드립니다.)
